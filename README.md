# [OPIS NIEAKTUALNY (NA RAZIE)] 🛡️ C++ DNS Parental Control Filter - Module (IPv4 AND IPv6)

> Oto lekki, asynchroniczny mini-serwer DNS napisany w C++ z wykorzystaniem interfejsu Winsock2, który służy jako podstawowy moduł kontroli rodzicielskiej do filtrowania niechcianych domen sieciowych w protokole **IPv4** i **IPv6**.
> ### Kod pisany hobbystycznie, bez formalnego wykształcenia inżynierskiego, ale za to z pełną obsługą wielowątkowości, WinSock2 i surowych buforów sieciowych. Praktyka > teoria.
